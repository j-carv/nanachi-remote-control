# Agent icons

Nanachi shows these marks beside the corresponding agent names in account settings.

- [Claude](https://claude.com/icon.svg) is a mark of Anthropic.
- The Codex icon comes from `webview/assets/codex-app-ga-logo.dfddfb85d7.png` in the official Windows app, package `OpenAI.Codex` version `26.1103.4239.0`. Codex is a mark of OpenAI.
- [Oh My Pi](https://github.com/can1357/oh-my-pi/blob/main/assets/icon.svg) publishes its icon in its MIT-licensed repository. The original notice is embedded in the SVG.
